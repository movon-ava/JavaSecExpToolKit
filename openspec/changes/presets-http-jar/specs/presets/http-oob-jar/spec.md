# Spec Delta: presets/http-oob-jar

## Purpose

规定 HTTP 带外 Jar 的能力：把「打成什么样的 Jar」与「Jar 落地后做什么」组合成产物，
托管在本机 HTTP 服务上，并把可访问地址交给使用者。该能力用于已授权的测试目标。

## ADDED Requirements

### Requirement: Jar 包装类型与末端动作的组合

系统 SHALL 提供多种 Jar 包装类型与多种末端动作，并允许使用者自由组合，
且每种组合都必须能构建出合法的 Jar 产物。

#### Scenario: 组合可构建
- **WHEN** 使用者选定任意一种 Jar 类型与任意一种末端动作后执行托管
- **THEN** 引擎构建成功
- **AND** 产物以 Zip 魔数 `PK\x03\x04` 开头

#### Scenario: 链序固定
- **WHEN** 展示任一组合的链路
- **THEN** 链路为「载体 → 包装类型 → 字节码转换 → 末端动作」
- **AND** 中间不缺少字节码转换节点

#### Scenario: 未知类型或动作被拒绝
- **WHEN** 请求一个不存在的 Jar 类型或末端动作
- **THEN** 不进行构建，并给出可读原因

#### Scenario: 不覆盖引擎默认值
- **WHEN** 某个输入留空
- **THEN** 该参数不下发给引擎
- **AND** 构建仍然成功

### Requirement: 本地托管与地址交付

系统 SHALL 把构建出的 Jar 托管在本机 HTTP 服务上，并给出一个可直接访问的地址，
且该地址必须指向实际监听的端口。

#### Scenario: 地址可访问
- **WHEN** 托管成功
- **THEN** 界面给出地址与实际监听端点
- **AND** 按该地址发起 GET 能取到与产物一致的字节

#### Scenario: 地址使用实际端口
- **WHEN** 使用者指定了一个自定义监听端口
- **THEN** 返回的地址使用该端口
- **AND** 不回落到其他默认端口

#### Scenario: 产物形态校验
- **WHEN** 托管成功
- **THEN** 界面给出产物的字节数与是否为合法 Zip 的结论
- **AND** 产物不是合法 Zip 时明确给出警告而不是当作成功

### Requirement: 停止托管释放端口

系统 SHALL 支持停止托管，并在停止后释放监听端口。

#### Scenario: 停止后端口可用
- **WHEN** 使用者停止托管
- **THEN** 界面报告已停止
- **AND** 该端口可以被再次绑定

#### Scenario: 退出程序释放端口
- **WHEN** 关闭程序时仍有处于托管状态的服务
- **THEN** 程序在退出前停止托管
- **AND** 不因为停止失败而无法退出

### Requirement: 参数不足必须给出可读结论

系统 SHALL 在参数不完整时给出可读结论，且不得启动服务或构建产物。

#### Scenario: 端口非法
- **WHEN** 端口不是 1-65535 之间的整数
- **THEN** 给出可读提示
- **AND** 不启动服务

#### Scenario: 动作必需的地址留空
- **WHEN** 所选末端动作需要 URL 而使用者未填写
- **THEN** 提示该地址不能为空并说明是哪个动作需要它
- **AND** 不构建产物

#### Scenario: 不需要的输入不可填写
- **WHEN** 所选末端动作不需要某一类输入
- **THEN** 对应的输入框被禁用
- **AND** 其标签说明该动作不需要它

### Requirement: 失败路径可读

系统 SHALL 在启动服务、构建载荷或发布任一环节失败时给出可读原因，且不得抛出未捕获异常。

#### Scenario: 端口被占用
- **WHEN** 目标端口已被占用导致服务启动失败
- **THEN** 给出「启动 HTTP 服务失败」与原因

#### Scenario: 构建或发布失败
- **WHEN** 载荷构建或发布失败
- **THEN** 给出对应的可读原因
- **AND** 界面不崩溃

#### Scenario: 尚未托管就复制地址
- **WHEN** 尚未成功托管就请求复制地址
- **THEN** 提示先托管 Jar
- **AND** 不写入剪贴板

### Requirement: 可持久化配置

系统 SHALL 把带外 Jar 的默认托管参数保存在配置文件中，并在下次进入页面时预填。

#### Scenario: 默认值被预填
- **WHEN** 在配置页保存默认绑定地址、端口、默认 URL、默认落地路径与默认执行参数后重新进入该页
- **THEN** 页面按保存的值预填

#### Scenario: 端口缺省可用
- **WHEN** 配置里没有保存过端口
- **THEN** 端口输入框仍有可用的默认值
- **AND** 首次托管不会因为端口为空而失败
