# Spec Delta: presets/preset-chain

## Purpose

规定内置预设链能力：把上游内置的预设模板读成界面可直接渲染的形态，
让使用者用现成模板出载荷，而不必每次都从空链自己搭。

## ADDED Requirements

### Requirement: 内置预设可读取并按分类筛选

系统 SHALL 读取上游内置的预设模板，并提供按分类筛选的入口。

#### Scenario: 载入内置预设
- **WHEN** 进入预设链页
- **THEN** 清单中列出全部内置预设
- **AND** 分类候选项来自预设文件本身，而不是代码里写死的常量

#### Scenario: 读取失败不影响其它功能
- **WHEN** 预设文件读取失败
- **THEN** 界面给出可读原因
- **AND** 其它功能仍可正常使用，不得因此崩溃

#### Scenario: 默认分类来自配置
- **WHEN** 配置页保存了默认分类后进入预设链页
- **THEN** 分类筛选预选为该分类

#### Scenario: 失效的默认分类被安全忽略
- **WHEN** 配置里的默认分类在当前预设中已不存在
- **THEN** 保持当前筛选状态
- **AND** 不得把清单清空

### Requirement: 链步骤与可填输入如实呈现

系统 SHALL 展示选中预设的链步骤与其可填输入，
输入控件的形态必须由预设声明的类型决定。

#### Scenario: 展示链步骤
- **WHEN** 选中一条预设
- **THEN** 按顺序展示其全部节点
- **AND** 展示每一步的默认参数

#### Scenario: 输入控件形态跟随声明类型
- **WHEN** 预设把某个输入声明为布尔型或带候选值
- **THEN** 分别渲染成勾选框或下拉框
- **AND** 使用者不需要猜合法取值

### Requirement: 预设可在本地生成载荷

系统 SHALL 用预设的载体、链步骤与输入值在本地构建载荷，并同时提供文本形态与可发送形态。

#### Scenario: 生成成功
- **WHEN** 使用者选中一条预设并点击生成
- **THEN** 状态栏报告成功与字节长度
- **AND** 输出区给出载荷的可复制形态与可记录的摘要

#### Scenario: 载体名与节点名的大小写差异被消化
- **WHEN** 预设里的载体名或节点名与引擎注册名的大小写不同
- **THEN** 生成仍然成功，不需要使用者手工改名

#### Scenario: 无可用载体时给出提示
- **WHEN** 选中的预设没有声明可用载体
- **THEN** 给出可读提示，不尝试生成

### Requirement: 预设生成的载荷可流转到其它功能

系统 SHALL 允许把预设生成的载荷交给载荷生成页或恶意服务器页继续使用。

#### Scenario: 发到恶意服务器
- **WHEN** 使用者点击「发到恶意服务器」
- **THEN** 服务页收到该预设的载体、链与已填参数
- **AND** 使用者在服务页选好服务后可直接发布

#### Scenario: 未生成时不得发送
- **WHEN** 尚未生成载荷就点击发送
- **THEN** 给出可读提示，不发送空内容

### Requirement: 预设链不修改引擎与预设文件

系统 SHALL 只读预设数据，不得在生成过程中写回预设文件。

#### Scenario: 生成不改动预设文件
- **WHEN** 生成任意数量的载荷
- **THEN** 预设文件与工作区其它文件均无新增或改动
