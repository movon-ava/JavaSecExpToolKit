# Spec Delta: analyze/call-graph

## Purpose

规定「调用链分析」的能力：用外部 CLI 引擎把目标 jar 解析成调用图数据库，
再以只读方式查询入口点、危险调用、字符串常量与组件清单；并规定反编译的边界。

## ADDED Requirements

### Requirement: 调用外部引擎建库

系统 SHALL 支持调用使用者指定的外部引擎，把目标 jar 解析成调用图数据库。

#### Scenario: 未配置引擎时给出可读提示

- **WHEN** 使用者未在配置页填写外部引擎 JAR
- **THEN** 给出可读提示并指明去配置页填写
- **AND** 不抛出未捕获异常

#### Scenario: 引擎路径不存在

- **WHEN** 填写的引擎路径不是存在的文件
- **THEN** 提前拦下并说明原因
- **AND** 不启动任何进程

#### Scenario: 数据库产物落到指定工作目录

- **WHEN** 引擎构建成功
- **THEN** 数据库文件出现在使用者指定的工作目录
- **AND** 报告给出该文件路径

### Requirement: 长时间任务必须有超时上限

系统 SHALL 为调用链分析设定超时上限，超时后终止引擎进程及其子进程。

#### Scenario: 超时终止

- **WHEN** 引擎在超时上限内没有完成
- **THEN** 系统终止该进程树
- **AND** 报告说明是超时而不是分析失败

#### Scenario: 超时低于下限时提前拦下

- **WHEN** 使用者填写的超时小于允许的下限
- **THEN** 在执行前拦下并说明下限
- **AND** 不启动引擎

#### Scenario: 临时目录被清理

- **WHEN** 引擎执行结束（成功或超时）
- **THEN** 引擎产生的临时目录被清理

### Requirement: 只读查询调用图数据库

系统 SHALL 以只读方式查询调用图数据库，且 MUST NOT 修改该数据库。

#### Scenario: 只读连接

- **WHEN** 执行任意一类查询
- **THEN** 数据库以只读方式打开
- **AND** 查询结束后数据库内容未变

#### Scenario: 数据库不存在

- **WHEN** 使用者尚未运行过调用链分析
- **THEN** 提示先执行调用链分析
- **AND** 不抛出未捕获异常

#### Scenario: 五类查询

- **WHEN** 数据库可用
- **THEN** 系统提供总览、入口点、Sink 命中、字符串常量、组件清单五类查询

#### Scenario: 关键字只作用于对应查询

- **WHEN** 使用者在非「字符串常量」查询里填了关键字
- **THEN** 该关键字不影响查询结果

#### Scenario: 缺少数据表

- **WHEN** 数据库缺少查询所需的表
- **THEN** 给出可读提示而不是堆栈

### Requirement: 危险调用清单可解释

系统 SHALL 内置危险调用清单，每条给出分类与用途说明。

#### Scenario: 命中输出分类

- **WHEN** 某个方法命中了清单中的调用
- **THEN** 输出该方法的所属类、方法名与命中分类

#### Scenario: 清单条数稳定

- **WHEN** 查看内置清单
- **THEN** 条数与实现一致，且不随查询次数变化

### Requirement: 反编译用于人工确认

系统 SHALL 提供反编译能力，把字节码还原成源码供人工确认，且产物只写不读。

#### Scenario: 整包反编译

- **WHEN** 使用者不指定类名并执行反编译
- **THEN** 输出该 jar 内的源码到指定目录
- **AND** 报告给出产出的源码文件数

#### Scenario: 指定类反编译

- **WHEN** 使用者指定一个存在的类名
- **THEN** 只输出该类的源码

#### Scenario: 类名不存在

- **WHEN** 使用者指定的类名在 jar 内不存在
- **THEN** 给出可读结论
- **AND** 不抛出未捕获异常

#### Scenario: 反编译不需要额外运行时

- **WHEN** 本机只有 JVM 而没有 Node
- **THEN** 反编译仍然可用
- **AND** 提示中说明无需 Node

#### Scenario: 超出时间预算

- **WHEN** 反编译耗时超过预算
- **THEN** 结果被标注为超出预算
- **AND** 已产出的源码仍然保留

### Requirement: 不新增第三方依赖

系统 SHALL 使用项目已有依赖实现调用链查询与反编译。

#### Scenario: 构建依赖清单不变

- **WHEN** 构建产物
- **THEN** 依赖清单与实现前一致
- **AND** 新增的查询脚本随产物一起打包
