# tools/file-upload Specification

## Purpose
规定「文件上传」小工具的能力：把本地文件按 multipart 表单发往指定接口，
并把这一次请求的原始响应如实地交回给使用者。该能力用于已授权的测试目标，
只负责「发送与记录」，不解析响应语义，也不做上传后的利用。

## Requirements

### Requirement: 单文件 multipart 上传

系统 SHALL 支持选择本地文件并按 `multipart/form-data` 发送一次 POST 请求，
且请求体中的文件内容必须与本地文件字节一致。

#### Scenario: 文件字节原样发出
- **WHEN** 选择一个本地文件并填写目标上传接口后执行上传
- **THEN** 目标收到的请求体包含该文件的原始字节
- **AND** 请求体包含该文件的文件名与表单字段名

#### Scenario: 请求体与声明一致
- **WHEN** 上传请求被发出
- **THEN** 请求头的 `Content-Type` 声明的 boundary 与请求体中使用的 boundary 相同

#### Scenario: 附加普通表单字段
- **WHEN** 使用者填写了附加表单字段的 JSON 对象
- **THEN** 这些字段以普通表单字段的形式出现在同一个请求体中

#### Scenario: 自定义字段名
- **WHEN** 使用者把表单字段名改为目标接口需要的名字
- **THEN** 请求体中的文件字段使用该名字
- **AND** 未填写时使用默认字段名

### Requirement: 响应结果如实记录

系统 SHALL 记录并展示这一次上传请求的响应状态码、耗时、响应头与响应体，
且响应体在精简报告下同样不得被省略。

#### Scenario: 响应原文可见
- **WHEN** 上传完成且目标返回响应
- **THEN** 结果区给出状态码、耗时、响应头与响应体原文
- **AND** 响应中的 `Set-Cookie` 被单独列出

#### Scenario: 跳转不被跟随
- **WHEN** 目标返回 3xx 跳转
- **THEN** 结果展示的是该跳转响应本身
- **AND** 结论中给出跳转提示与 Location

#### Scenario: 连接失败可读
- **WHEN** 目标不可达或连接超时
- **THEN** 结论为「上传失败」并给出原因
- **AND** 不抛出未捕获异常

### Requirement: 上传失败必须给出可读结论

系统 SHALL 在参数不完整或文件不可用时给出可读结论，且不得发出请求。

#### Scenario: 目标 URL 为空
- **WHEN** 未填写目标 URL 就执行上传
- **THEN** 给出「目标 URL 不能为空」的提示
- **AND** 不发出任何请求

#### Scenario: 未选择文件
- **WHEN** 未选择本地文件就执行上传
- **THEN** 给出可读提示说明需要先选择文件
- **AND** 不发出任何请求

#### Scenario: 文件不可读或超过上限
- **WHEN** 选定路径不存在、不是普通文件，或超过单文件大小上限
- **THEN** 不发出请求，并说明该文件被跳过的原因

#### Scenario: 附加字段不是合法 JSON
- **WHEN** 附加表单字段的内容不是 JSON 对象
- **THEN** 给出可读原因
- **AND** 不发出任何请求

### Requirement: 可持久化配置

系统 SHALL 把上传功能的默认参数保存在配置文件中，并在下次启动时预填到页面。

#### Scenario: 默认值被预填
- **WHEN** 在配置页保存默认上传 URL、默认表单字段名与上传超时后重启程序
- **THEN** 文件上传页按保存的值预填

#### Scenario: 留空不覆盖
- **WHEN** 配置页里某一项留空
- **THEN** 该配置项不下发，页面保留自身初值

### Requirement: 报告不泄露无关凭据

系统 SHALL 不在上传结论中输出本次请求未使用的凭据。

#### Scenario: 仅回显显式给出的请求头
- **WHEN** 使用者填写了请求头
- **THEN** 报告中回显的请求头仅包含使用者显式给出的那些
